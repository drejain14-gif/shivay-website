# Shivaay Technocrat Service

Next.js 14 marketing site for **Shivaay Technocrat Service** — NABL-accredited mechanical laboratory and civil infrastructure testing / consultancy (Jaipur, India).

## Stack

- Next.js 14 (App Router), TypeScript, Tailwind CSS
- GSAP + ScrollTrigger, Lenis (gated by `prefers-reduced-motion`)
- Content modules in `src/content/`
- Brand guidelines in `docs/brand-guidelines.md`
- Scraped archive in `content/scraped/`

## Scripts

```bash
export PATH="$HOME/.local/node/bin:$PATH"
npm run dev
npm run build
npm start
npm run lint
```

## Phase 1 scope

Brand identity + Home page (lab / geotech / pile / NDT first). Solar is deprioritized and not featured on Home.
